# Pipeline Templates

A coleção `pipeline_templates` armazena nome, slug único, categoria e `stages` JSON. Execute a migração SQL e `node scripts/seed-pipeline-templates.mjs` com `DIRECTUS_URL`/`DIRECTUS_TOKEN` para carregar os cinco fluxos predefinidos. A galeria está em `/definicoes/pipelines/templates`; o wizard de criação em `/definicoes/pipelines/new` suporta seleção, pré-visualização, personalização e confirmação.
